## Goal

Install the Claude Code hooks that enforce the guardrails: `PreToolUse(Edit, Write)` blocks off-spine edits when no story is picked; `PostToolUse(Edit, Write)` captures edits to the picked story's changelog.

## Scope

- Implement the `PreToolUse(Edit, Write)` hook script
  - Reads `.kadai/.picked` and `[guardrail.allowed_paths]` from config
  - If no story picked AND target path is outside `.kadai/` AND not in the allowlist → exits non-zero with clear message
  - Honors `KADAI_BYPASS=1` env var (with audit logging to `.kadai/bypass.log`, including `KADAI_BYPASS_REASON` if set)
- Implement the `PostToolUse(Edit, Write)` hook script
  - If a story is picked AND `change_capture.enabled = true` → appends entry to that story's `changelog.md` (timestamp, file path, one-line summary)
- Add MCP tool `record_change(story_id, files, summary, commit?)` — the hook can call it, or write directly to changelog.md (decide during plan writing)
- Extend `kadai init` to install hook entries into `.claude/settings.json` (merged, not overwritten)
- Add config sections `[guardrail.allowed_paths]` and `[change_capture.enabled]` to `kadai init`'s default config.toml
- Tests: hook scripts return correct exit codes given various states (picked/unpicked, allowed/disallowed paths, bypass on/off)
